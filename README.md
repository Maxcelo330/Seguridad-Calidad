# Dashboard de Seguridad · Aseguramiento de Calidad (Embol S.A.)

Desvíos SSMA (actos inseguros, condiciones inseguras, cuasi accidentes y medio ambiente)
con foco en los reportes emitidos y recibidos por el área de Calidad.

- `app.py` — aplicación Streamlit (Main file path: `app.py`)
- `data/BD_SEGURIDAD_CALIDAD.db` — base consolidada
- `.streamlit/config.toml` — colores (tema claro / oscuro)
- `requirements.txt` — librerías
